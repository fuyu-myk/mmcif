## Explained differences

Each rule in `harness/explained.toml` that matched in this run.

### assembly_set in any entry (checked by hand on 3zue)

gemmi 0.7.5 drops assemblies whose _pdbx_struct_assembly.details it does not recognise, such as 'icosahedral asymmetric unit', 'helical asymmetric unit', 'point asymmetric unit' and 'crystal asymmetric unit, crystal frame'. Checked on all 13 entries this covered in October 2026 by relabelling every details value as author_defined_assembly: gemmi then reports these assemblies and agrees with ours, except on composite expressions such as (X0)(1-60), of which it expands only the first group (see 1m4x); there ours matches oligomeric_count in 1ihm, 1rui, 2buk and 7c9t

- Covers messages containing `only in ours`.
- 53 differences in 13 entries: 1ihm, 1m4x, 1rmv, 1rui, 2buk, 3zue, 4llf, 6iic, 7bue, 7c9t, 7fej, 7yhk, 8y3j

### assembly_atom_count in 1m4x

gemmi 0.7.5 expands only the first group of '(1-60)(61-88)', giving 180 copies; ours gives 1680 x 3 = 5040, matching oligomeric_count 5040, and right-to-left composition places every copy on a 775-898 A capsid shell

- Covers messages containing `assembly 1:`.

### b_iso in 8zzt

8zzt is an integrative model and gives '.' for every _atom_site.B_iso_or_equiv. Ours reads a missing B-factor as 0.0 and gemmi 0.7.5 as 20.0; neither value is in the file
